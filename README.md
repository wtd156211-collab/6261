# 块级统计与查询剪枝（从 0 实现）

仓库里只有这份说明、`samples/**` 与 `.gitignore`，没有实现代码。交付：`zonecut` 包（Python 3.13，只用标准库）、`python -m zonecut` 命令行、用样例生成的 `web/blocks.html`、`tests/`（`unittest`）。

## 1. 范围

要做：单表单列的块级统计与剪枝——建索引时按块算好 `ts` 的最小、最大、行数与空块标记；查询先用统计剪掉整块、只扫剩下的块，结果与逐行全扫完全一致；追加或改写后统计跟着更新，不许重扫全表、不许重建索引；页面把每块状态摊开。

不做：多列条件与联合统计、`or`/`not`、多表、聚合、排序、分页；删除行、改 id、改块容量；并发与事务；压缩与列存；联网、第三方依赖与构建步骤。

## 2. 口径与公式

### 2.1 块与统计

块按 `id` 切：容量 `S`（行/块）由实现选定，全表统一、`S ≥ 1`、建索引时定下并写进索引。块号 `b = id // S`，块 `b` 覆盖 `id ∈ [b·S, (b+1)·S−1]`，块数 = `⌊最大 id / S⌋ + 1`。一块里没有任何行就是空块，也要占一个槽位、也要算进块数。每块维护 `rows`、`min_ts`、`max_ts`（空块为空）、`empty`（`rows == 0`）四项。

### 2.2 剪枝判据

块内 `min_ts = m`、`max_ts = M`。非空块按下表判：能剪就整块不读，不能剪就得逐行判；空块任何条件都剪掉。边界算命中：`M == V` 时 `ge V` 不能剪、`gt V` 必须剪。`ne V` 只在整块所有行都等于 `V` 时才能剪，`V` 落在 `[m, M]` 之外不是剪枝理由。剪枝率 = `1 − 扫描块数 / 总块数`（含空块）。

| 条件 | 整块剪掉当且仅当 |
| --- | --- |
| `eq V` | `V < m` 或 `V > M` |
| `ne V` | `m == M == V` |
| `lt V` | `m ≥ V` |
| `le V` | `m > V` |
| `gt V` | `M ≤ V` |
| `ge V` | `M < V` |
| `between A B`（闭区间，`A ≤ B`） | `B < m` 或 `A > M` |
| `and [条件…]` | 任一项能剪掉这一块 |

## 3. 数据结构与更新规则

索引里每块存四项加一个定位这一块行的位置；行留在数据文件里，整表不进内存。索引文件格式自定。

- 建索引：顺序读一遍数据文件，逐行更新所在块的 `rows`/`min_ts`/`max_ts`，块号有空洞就登记中间的空块。
- 追加 `append(id, ts)`：`id` 必须大于当前最大 `id`。空块变非空（`rows` 0→1，`min_ts = max_ts = ts`）；非空块 `rows` 加一、`min_ts`/`max_ts` 取并集；跨到新块号时中间块号登记成空块。
- 改写 `set-ts(id, ts)`：`id` 必须已存在。新值落在 `[min_ts, max_ts]` 内统计不变；把区间撑大只改被撑的那一侧；旧值正好是边界而新值把边界收回（旧值 = `min_ts` 且新值更大，或旧值 = `max_ts` 且新值更小）就只重算这一块的 `min_ts`/`max_ts`——重读这一块的行（≤ `S` 行），块里只有一行就直接取新值。
- 禁令：追加与改写都不许重扫全表、不许重建整个索引；改写只许读被改写那一块；查询不许改写索引文件。

## 4. 输入输出与文件格式

### 4.1 数据文件

定长文本，一行一条：12 位 `id` + 空格 + 12 位 `ts` + LF，共 26 字节；字段十进制、左补 0、不带符号，取值 `[0, 10¹²)`。行按 `id` 严格递增，`id` 允许空洞，每一行的字节位置固定。

### 4.2 查询与变更文件

UTF-8 无 BOM、LF 行尾、末行有换行，一行一个对象。查询：`{"id": "q-01", "op": "between", "lo": 1000, "hi": 1306}`——`id` 全仓库唯一；`op` 取 `eq`/`ne`/`lt`/`le`/`gt`/`ge`/`between`/`and`，比较形式写 `value`、`between` 写 `lo`/`hi`、`and` 写 `args`（≥ 2 个原子条件、不嵌套、都作用在 `ts` 上）；样例都是合法输入。变更：`{"op": "append", "id": 40, "ts": 3500}` 或 `{"op": "set-ts", "id": 0, "ts": 3295}`，按行序执行。

### 4.3 命令行

```
python -m zonecut build  <数据文件> <索引文件> [--block-size <S>]
python -m zonecut query  <数据文件> <索引文件> <查询文件> [--report <报告文件>]
python -m zonecut update <数据文件> <索引文件> <变更文件>
python -m zonecut page   <数据文件> <索引文件> <查询文件> --query <查询 id> --out <HTML 文件>
```

`query` 按查询文件的行序跑，stdout 每条一段：先 `# <查询 id> <命中行数>`，再按 `id` 升序一行一条 `<id>` + TAB + `<ts>`。`--report` 另写报告：首行 `# 块容量 <S> 总块数 <B> 行数 <N>`，其后一条查询一行五列 TAB——查询 id、命中行数、扫描块数、跳过块数、总块数。`update` 就地改数据文件与索引文件。退出码 0 成功；1 输入不可用（文件缺失、格式不合法、`id` 不递增或不存在、追加的 `id` 不大于当前最大 `id`、条件形式不支持）；2 用法错误；非 0 不写输出，块容量不给就自己定。

### 4.4 页面

`page` 写一份自包含单文件 HTML：UTF-8、不引外部资源、双击可开、`<script type="module">` 内联、逐块一行。顶部四项各一个带 `data-key` 的元素：`scanned`、`skipped`、`blocks`、`prune-rate`（一位小数百分数）；`id="blocks"` 的 `<table>` 每块一行 `<tr data-block data-state data-rows data-min data-max data-empty>`，按块号升序，`data-state` 取 `hit`（块内有命中，绿）、`scanned`（扫过没命中，黄）、`skip`（剪掉，灰），`data-empty` 取 `0`/`1`，空块的 `data-min`/`data-max` 写 `-`。页面上的数字只能来自引擎输出，页面不重算、不再读数据文件。

## 5. 性能与验收口径

只用标准库、单进程单线程。规模用例 100 万行，配方见 `samples/data/scale.md`（本地生成，不入库）。

预算：`build` ≤ 5 s；200 条查询同一进程跑完 ≤ 3 s、单条 ≤ 50 ms；200 次变更（追加与改写交替）≤ 5 s；`page` ≤ 3 s 且产出 ≤ 8 MiB。索引占用：索引文件 ≤ `行数 × 1 字节 + 512 KiB`；`build` 与 `query` 的峰值分配（`tracemalloc` peak）≤ `行数 × 2 字节 + 4 MiB`（100 万行下分别约 1.5 MiB 与 6 MiB）。剪枝率：整组 200 条平均 ≥ 0.99，单条最低 ≥ 0.95。

1. `query` 的 stdout 与 `samples/expected/<同名>.txt` 逐字节相同（行序敏感）。
2. 每条查询的扫描块数不超过 `samples/expected-pruning.txt` 给的上界；写 `0` 的必须一块都不扫。
3. 同一输入连跑两次，stdout、报告与页面逐字节相同：不写时间戳、绝对路径、主机名，也不依赖哈希遍历顺序。
4. `sync` 组的期望结果是变更之后算的：追加没进索引会漏行，统计没收缩会多扫，两种都算不过。
5. 规模用例按上面的预算与剪枝率门槛核对；`python -m unittest` 能跑通，测试只读 `samples/`。

## 6. 样例说明

`samples/data/<名>.txt` + `samples/queries/<名>.jsonl` 的期望 stdout 在 `samples/expected/<名>.txt`；`samples/expected-pruning.txt` 给每条查询的扫描块数上界（`S` 是你选的块容量）；`samples/notes.md` 是现场记录。

| 组 | 行数 | 场景 |
| --- | --- | --- |
| `cut` | 40 | 完全剪掉：两条在整表 `ts` 之外（0 块），两条落在两簇之间的空隙 |
| `part` | 42 | 部分命中：六条 `ts` 带，`between` 跨带、`and` 取开区间、`and` 里用 `ne` 挖洞 |
| `edge` | 24 | 边界压线：端点等于全表最小/最大值，`ge`/`gt`、`le`/`lt` 成对，`ne` 落在常量值上 |
| `sync` | 30 → 33 | 先建索引，再跑 `sync-ops.jsonl`，查询在追加与改写之后 |

`sync` 的改写覆盖撑大、收回边界、区间内不变三条规则，追加覆盖空块登记与尾部新增；小样本核对结果与边界口径，剪枝率门槛在规模用例上核对。
